James Beattie's local install using M3 processor + homebrew clang compilers

CPU build

General compile for test problems.

cmake --preset beattie-cpu
cmake --preset beattie-cpu-heffte
cmake --preset beattie-cpu -DPROBLEM=current_sheet
cmake --preset beattie-cpu -DPROBLEM=kh

Equivalent explicit command for heFFTe-enabled build:
cmake .. -DAthena_ENABLE_MPI=ON -DAthena_FFT_BACKEND=HEFFTE -DCMAKE_PREFIX_PATH="$HEFFTE_PREFIX"

Examples with/without an FFT backend:

With KokkosFFT (default):
mkdir -p build-fft
cd build-fft
cmake .. -DPROBLEM=current_sheet_2zone -DAthena_FFT_BACKEND=KOKKOS
cmake --build . -j8

Without FFT:
mkdir -p build-nofft
cd build-nofft
cmake .. -DPROBLEM=current_sheet_2zone -DAthena_FFT_BACKEND=NONE
cmake --build . -j8

Choose exactly one of NONE, KOKKOS, or HEFFTE.
